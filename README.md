## 📑 家庭 CFO 財務核心操作指南

### 🎯 終極核心金句

> **「記帳是在記錄我的現金流；財務報表是在呈現資產的變化。」**

---

### 一、記帳篇：記錄現金流（日常的行車紀錄器）

日常記帳（1月～11月）的核心任務是**看管流動性**，確保手頭隨時有真金白銀可以運轉。為了精準掌握家庭的生存與擴張能力，必須實施「雙軌分類法」，將流出的資金嚴格區分：

#### 🔴 軌道一：實際支出（費用軌道）

- **定義**：錢流出去就永遠消失了，換回來的是當下的生活體驗、基本生存或服務代價
- **項目**：外食、買菜、日常開銷、水電費、稅金、**房貸利息**（給銀行的代價）
- **核心價值**：這是家庭的**真實生活成本**。只要掌控好這一軌，就能解放記帳焦慮
- **系統實作**：KPI「支出」、cno=1~12 等消費類

#### 🟢 軌道二：現金轉換資產（轉帳軌道）

- **定義**：現金流雖然減少了，但錢沒有消失，只是換了另外一種更具生產力的面貌留在家裡
- **項目**：**房貸本金**（從「銀行存款」轉入「房貸負債帳戶」）、買股本金
- **核心價值**：還本金/買股不是消費，而是把資產「一磚一瓦買回來」的過程
- **系統實作**：`mode='信用卡支出'`（買股 cno=14）、房貸本金（理論上應拆出，目前狀態待釐清）

#### ⚪ 特殊項目：直接從收入扣除的股票（怡亭凱基定期定額）

- **心法**：**日常完全不記！** 因為這筆錢沒變成現金流進日常帳戶
- **理由**：為了不讓現金流與銀行對帳單亂掉，日常直接忽略它
- **系統呈現**：ChartPage Tab A「💧 月別資金變動」圖以粉色折線單獨追蹤怡亭-凱基股票月增，作為定期定額金額視覺化

---

### 二、核心精髓：家庭自由現金流

【實質收入】−【實際支出】= **家庭自由現金流（Free Cash Flow）**

#### 涵義

家庭的「核心生存與擴張超能力」。在維持目前生活品質的前提下，每個月真正賺到、沒有負債包袱、可以自由支配的真金白銀。

#### 如何「創造財富」

- **消滅利息（防守）**：拿去還房貸本金，消滅未來複利滾動的利息
- **養大資產（進攻）**：買進高股息 ETF 或市值型股票，生股利形成正向循環
- **撿寶機會（套利）**：市場大跌時，充沛現金讓你有最高選擇權

---

### 三、財報篇：呈現資產變化（年度的全身健檢）

每年 12 月 31 日，關掉記帳本，用經典公式：

```
資產 − 負債 = 淨資產
今年底淨資產 = 年初淨資產 + (今年實質收入 − 今年實際支出)
```

#### 📊 年度家庭資產負債表結構

| 區塊 | 包含項目 | 系統管道 / 實務心法 |
|------|---------|------------------|
| **【左：總資產】** | 流動資產：銀行活存/定存 | asset_snapshot category='資金' & 非股票名 |
| | 投資資產：凱基證券總市值 | asset_snapshot category='資金' & isStockAccount(name) — **直接認列最新總市值，讓隱形資產年底現形** |
| | 固定資產：房屋與土地現值 | asset_snapshot category='動產/不動產' |
| **【右：總負債】** | 長期負債：房貸剩餘本金 | asset_snapshot category='負債'（桃園房貸 ano=24）— 自網銀房貸專區查 12/31 賸餘本金 |
| | 短期負債：信用卡未結款 | （目前未獨立追蹤）|
| **【底層：淨資產】** | （總資產 − 總負債） | 今年淨資產 − 去年淨資產 = 當年財富真正長大成果 |

> ⚠️ **未實現損益（市值波動）不入 money 表**。`money` 表追蹤現金流，`asset_snapshot` 反映當下市值，兩者天然有差額 = 未實現損益，這是**特性不是 bug**。

---

### 💡 CFO 的終極工作流

| 時間 | 任務 | 工具 |
|------|------|------|
| 日常 1月～11月 | 管「現金流」、確保自由現金流健康、避免流動性危機 | EntryPage / BudgetPage / Tab A 月別 |
| 年底 12/31 | 看「財務報表」、盤點「資產變化」 | AssetPage / Tab B 比對表 |

**最終洞察**：日常記帳本天天記錄現金流出，會讓人有「變窮錯覺」；但年底一算財報，那些流出的現金，早已化成「長大的股票」與「減少的房貸負債」，淨資產一直在默默滾大。

---

### 對帳驗證公式（投資專用）

```
完全清倉時：  累積買入支出 − 累積賣出收入 − 累積配息 = 資產淨值變化
持股中時：    差額 = 未實現損益（正常，市值波動）
```

若**清倉後**對不上 → 記帳有遺漏（漏買 / 漏賣 / 漏配息）
若**持股中**對不上 → 多數是未實現損益，屬正常

例：2021 年投資資產年增 244 萬但 cno=14 紀錄為 0 → 抓出漏記，補錄 6 筆台積電股票買進共 243.9 萬，差額剩 0.3 萬（合理）。
